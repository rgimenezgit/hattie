# .claude

Configuração do Claude para este projeto.

- `skills/`: instruções reutilizáveis (`hattie-voz`, `hattie-visual`, `hattie-prompt-imagem`, `hattie-registrar-decisao`). Cada skill é uma pasta com um `SKILL.md`.
- Novas peças de automação entram aqui: `agents/` para agentes de apoio e `commands/` para atalhos, quando fizerem falta.

O contexto geral do projeto está em `CLAUDE.md` na raiz.
