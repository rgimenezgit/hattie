# Glossário interno

| Termo | Significado |
|---|---|
| Palco | Registro alto da marca: lilás, violeta e lima, para posts, capas e lançamentos |
| Gabinete | Registro calmo: branco e preto, para a plataforma |
| plimm | Botão de criar e som de criação |
| Selo de som | Pílula com onomatopeia (plimm, hmm…, tcharam, cling, zuum, puff, toc toc, psiu) |
| Saiu do chapéu | Expressão própria para anunciar que algo ficou pronto |
| Cérebro de marca | Memória da marca de onde nascem as decisões |
| Studio infinito | Estilo fotográfico: espaço de uma cor só, sem horizonte |
| ✱ | Grafismo oficial da marca, topo da escala de glifos das faíscas |
| Efeito sonoro | Onomatopeia de magia que acompanha uma ação (plimm, puff, tcharam, cling, zuum, hmm…) |
| Zona zero | Preço, prazo, erro e cobrança: tom direto, sem selo e sem piada |
