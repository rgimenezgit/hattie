# Grafismo

Gradiente em pontos, pontos interativos e faíscas em canvas, com as cores da paleta. Regras em `8-grafismo-e-gradiente.md`.

- Os quadros interativos seguem o cursor; sem mouse, o foco se move sozinho. Com movimento reduzido ficam em repouso.
- Versão publicada: página "Grafismo Hattie".
- `hattie-asterisco.svg`: o ✱ oficial, usado como glifo das faíscas.
