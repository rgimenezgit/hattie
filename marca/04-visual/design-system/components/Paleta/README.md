# Paleta

Quatro famílias, cada uma com uma cor clara e uma forte, mais neutros. Detalhes e contrastes em `1-cor.md`.

- Lima `#E6F344` e lima-forte `#77A00F`
- Lilás `#B19DFC` e violeta `#7F3AEF`
- Rosa `#FF8AE5` e rosa-forte `#F53890`
- Azul `#8AD3FA` e azul-forte `#1764D6`
- Neutros: branco, cinza, cinza-médio, grafite e preto
