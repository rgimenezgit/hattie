# Personagem

O Hattie, mago masculino, em SVG de uma cor.

- `avatar`: versão neutra, para perfil e balões de fala.
- `feliz`, `bravo` e `entediado`: expressões desenhadas pelo Raphael, em preto.

A ficha completa (character sheet) segue em refação; as expressões acima entram nela. O personagem fala em primeira pessoa e acompanha no máximo um selo de som por peça.
