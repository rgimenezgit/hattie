# 04 · Visual

Tudo o que a marca mostra. O Design System é a fonte da verdade e a pasta `design-system/` guarda os documentos, os tokens e as páginas de exemplo.

| Cor, temas e proporções | `design-system/1-cor.md`, `tokens.json`, `tokens.css` |

| Sons e botão plimm | `design-system/3-sons-e-botao-plimm.md` |

| Pendências do sistema | `design-system/5-pendencias.md` |
