# Fontes

- **Clash Display** (variável, 200 a 700): títulos em minúsculas, peso 500. O peso 700 pertence ao logotipo.
- **Poppins** (família completa em `poppins/`: Thin 100 a Black 900, cada peso com itálico, e a licença `OFL.txt`): corpo de texto e rótulos. Na plataforma, os pesos em uso são 300, 400, 500 e 600 (`plataforma/design/diretrizes-ui.md` §3).

Confira a licença de cada família antes de distribuir os arquivos fora do projeto (a Poppins usa a SIL Open Font License).
