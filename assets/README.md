# Assets

Arquivos finais da marca, prontos para uso.

| Pasta | Conteúdo |
|---|---|
| `logos/` | Logotipo, logomarca e símbolo em preto e em branco |
| `personagem/` | Avatar e expressões do Hattie |
| `icones/` | Ícones e grafismos desenhados (base, propostos e puff) |
| `grafismos/` | ✱ oficial |
| `fontes/` | Clash Display e Poppins |
| `pecas/` | Cards de marca e peças prontas |
| `fotografia/` | Referências aprovadas de fotografia |
| `ilustracao/` | Ilustrações aprovadas |

Nomes de arquivo em minúsculas, com hífen, prefixo `hattie-` nos arquivos de marca. Versão em branco termina em `-branco` ou `-branca`.
