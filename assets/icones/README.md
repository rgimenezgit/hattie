# Ícones e grafismos

- `base/`: desenhos do Raphael (grafismos, ícones e o botão plimm). Castelo é a home, vassoura é enviar, caderno é a biblioteca.
- `propostos/`: ícones novos desenhados no mesmo estilo. Porta (toc toc) e olho (psiu) são do Raphael; os demais aguardam aprovação ou redesenho.
- `puff/`: a nuvenzinha do som puff.

Regras de cor, tamanho, respiro e uso em `marca/04-visual/design-system/9-grafismos-e-icones.md`. SVGs em preto `#101010`; para outra cor, troque o preenchimento ou use `currentColor`.
