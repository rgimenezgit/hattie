# Fotografia

Conjunto de referência do estilo studio infinito: 15 a 30 imagens aprovadas, com o hex do fundo na legenda. Regras e prompt base em `marca/04-visual/design-system/6-fotografia-studio.md`.

## Exemplos (`exemplos/`)

Todos com fundo lima `#E6F344`, em JPEG de 2400 px no lado maior.

| Arquivo | Cena |
|---|---|
| `exemplo-01-hattie-poltrona-lima` | Hattie de chapéu e robe, na poltrona lima, com notebook |
| `exemplo-02-hattie-com-logotipo` | Hattie com o logotipo na imagem |
| `exemplo-03-hattie-terno-lilas-tenis-branco` | Hattie de terno lilás, cadeira branca e tênis branco |
| `exemplo-04-hattie-robe-roxo` | Hattie de chapéu e robe violeta, tênis lima |
| `exemplo-05-cliente-cosmeticos` | Cliente com cesta de cosméticos |
| `exemplo-06-cliente-confeitaria-horizontal` | Cliente com bandeja de confeitaria, horizontal |
| `exemplo-07-cliente-confeitaria-vertical` | Cliente com bandeja de confeitaria, vertical |
| `exemplo-08-cliente-moda` | Cliente com peças de roupa nos braços |
