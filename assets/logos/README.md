# Logos

Seis arquivos em SVG de uma cor: três em preto (`#101010`) para fundos claros e três em branco para fundos escuros e coloridos.

- `hattie-logotipo`: wordmark, com o pingo do "i" em forma de ponta de chapéu.
- `hattie-logomarca`: personagem com o wordmark.
- `hattie-simbolo`: ícone de marca para avatar e favicon.

O ✱ é grafismo da marca, fora do logo. Área de respiro mínima: a altura do "h" em volta.

## Aplicações com cor (`aplicacoes/`)

Seis arquivos em SVG de uma cor, para fundos de marca:

- `hattie-simbolo-violeta`, `hattie-logotipo-violeta`, `hattie-logomarca-violeta`: violeta `#7F3AEF`, para fundo lima `#E6F344`.
- `hattie-simbolo-lima`, `hattie-logotipo-lima`, `hattie-logomarca-lima`: lima `#E6F344`, para fundo violeta `#7F3AEF`.
- Preto sobre lima usa os arquivos base em preto.
