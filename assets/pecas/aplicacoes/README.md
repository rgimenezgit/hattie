# Aplicações

Peças-exemplo que juntam logo, tipografia, cor, fotografia, ilustração, grafismo e som nas proporções de cada contexto. Servem de referência visual; cada uma pode ser refeita com os arquivos de `assets/`.

| Arquivo | Peça |
|---|---|
| `aplicacao-01` | Foto de estúdio com o logotipo dentro da imagem |
| `aplicacao-02` | Story com foto de estúdio e faixa violeta |
| `aplicacao-03` | Hero da landing |
| `aplicacao-04` | Slide de apresentação com faixa de pontos |
| `aplicacao-05` | Tela inicial da plataforma, com filete de pontos |
| `aplicacao-06` | Post 4:5 com violeta dominante e ilustração |
| `aplicacao-07` | Entrega de logo com ilustração e selo tcharam |
